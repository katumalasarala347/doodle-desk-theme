# Doodle Desk - Multi-Theme System

This is an implementation of a **multi-theme frontend system** for the GoGetWell.ai platform. It supports dynamic theme switching based on medical specialties.

##  Features

-  3 Themes: Default, Cosmetic, Transplant
-  Theme switching using Zustand state management
-  Theme persists using localStorage
-  Tailwind CSS with dynamic CSS variables
-  Custom color, typography, and layout per theme
-  Fully responsive and mobile-friendly

##  Technologies Used

- React + TypeScript
- Zustand for theme state
- Tailwind CSS (with custom theme variables)

npm start
